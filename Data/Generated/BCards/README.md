# Generated BCard catalogs

This directory is maintained by `Tools/NosGM.DataUpdater`.

Do not edit generated JSON files manually. Corrections to extraction behavior belong in the updater; corrections to server behavior belong in the corresponding NosGM BCard handler.

Expected generated files include one `BCard_<LANGUAGE>.json` catalog per supported configured language, a stable `manifest.json` and `CHANGE_REPORT.md`.

The updater was adapted from `noszanou/BCardGistUpdater` commit `53153c990ae5b65a603d223eeda504df2a67d5fb`. Attribution and GPLv3 terms are documented in `Tools/NosGM.DataUpdater/NOTICE.md`.

Proprietary NosTale client archives and extracted binary assets must not be committed to this directory.
